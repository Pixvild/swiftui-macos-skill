# 窗口与场景

性质：作者编写的实施指南，不是 Apple 官方译文。证据入口见 [来源卡片](../source-notes.md)：SW04、SW05、SW06。

## 已核对的官方信息

SW04 的 Overview 和窗口关闭说明区分了唯一窗口与窗口组，并指出主场景采用 Window 或 WindowGroup 时，最后窗口关闭的行为可能不同。SW05 描述了按数据值呈现窗口组的具体初始化器。SW06 展示了使用 Settings 场景提供设置界面的方式。阅读状态均为官方检索正文片段，具体声明及版本仍需原页或 SDK 核验。

## 实施顺序

先写一个窗口清单：主编辑窗口、同文档第二窗口、设置窗口、工具窗口。每项注明是否允许多个实例、对应数据身份、关闭后如何处理未保存数据，以及下一次打开应恢复哪些状态。

按需求比较单例窗口、可重复窗口组或文档场景，不按“应用看起来只有一个窗口”直接定型。打开窗口的路由标识和文档身份是不同概念；不要用一个全局当前文档变量替代每个窗口自己的编辑上下文。

在最小原型中先验证开关窗口，再加入尺寸、工具栏、材质和状态恢复。优先复用当前工程已采用的模式；只有发现功能缺口才调整架构。

## 需要检查的边界

关闭最后一个窗口后的进程和菜单行为；从 Dock 重新激活；打开相同数据是否复用窗口；切换两个窗口后的命令目标；设置窗口重复打开；最小窗口尺寸；不同显示器与全屏；窗口恢复失败后的退路。

不要在未经核验时写死“某场景一定从某版本开始支持”。每个初始化器和修饰符分别核验，并保留实际 SDK 中的声明。

用“窗口角色—候选 API—数据所有者—目标系统支持—验证方法”描述方案。把 Window 与 WindowGroup 的关闭差异列入测试，而不是只提交一张布局截图。
